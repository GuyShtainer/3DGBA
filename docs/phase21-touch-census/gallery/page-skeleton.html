Sharp text — the same pixels, before and after

Text was drawn at scales like 0.585× and 0.702× against fonts baked at fixed sizes — a bitmap font resampled off 1.0 is blurry by construction. Every text role now draws at exactly 1.000× on an integer origin. These strips are the identical crop from the identical screen, before and after.

Every text role, rendered from the shipped font bytes

Native 3DS resolution, no emulator upscaling in the way. The proof is binary: after the fix every glyph pixel is an exact multiple of 17 — the only values the glyph sheet can contain — which is possible only at scale 1.0 with an integer origin. Off-values went 530 → 0; distinct grey levels 217 → 15.
